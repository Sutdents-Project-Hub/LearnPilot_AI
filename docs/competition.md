# 智學領航 LearnPilot AI｜競賽與 Demo 規劃

## 1. 展示定位

一句話：

> 智學領航把學生零散的學習紀錄轉成「目前狀態、風險原因與下一步行動」，讓努力不只被記錄，也能被導航。

本專案展示的是 competition prototype，不是 production 產品。Demo 使用匿名合成資料與本機規則，沒有真實 AI model、雲端同步、帳號或學生個資。

## 2. 評審應記住的三件事

1. **看見現在**：把讀書時間、正確率與專注度整理成可理解的學習狀態。
2. **提早看見風險**：在成績明顯退步前指出趨勢與原因。
3. **知道下一步**：把洞察轉成具體的時段、科目與複習任務。

## 3. 標準 4 分鐘 Demo

實際競賽時長尚未確認；以下先以 4 分鐘設計，可縮成 2 分鐘或延伸成 6 分鐘。

### 0:00–0:30｜問題

- 學生留下很多學習資料，但通常只看到單次成績。
- 問題往往到考試退步後才發現。
- 今天示範如何從資料得到可執行的下一步。

畫面：今日總覽。

### 0:30–1:10｜現在在哪裡

- 顯示匿名學生「小航」今日完成度、整體效率與五科概況。
- 指出數學投入時間不少，但效率正在下降。

畫面：今日、科目分析。

### 1:10–2:00｜可能的風險

- 開啟數學風險詳情。
- 顯示趨勢、投入落差、效率下降與資料筆數。
- 強調這是規則式趨勢提示，不是保證退步的預言。

畫面：分析、風險詳情。

### 2:00–2:50｜下一步怎麼走

- 系統找出 19:00–21:00 是相對高效時段。
- 建議把數學錯題複習安排到該時段。
- 使用者接受建議，今日計畫立即更新。

畫面：建議詳情、計畫。

### 2:50–3:30｜成長閉環

- 以後續合成紀錄展示執行計畫後的趨勢。
- 回到「資料 → 洞察 → 行動 → 成長」。

畫面：歷程、成長回顧。

### 3:30–4:00｜誠實收尾

- Demo 全程本機運作，不需要網路。
- 現階段以可解釋規則驗證產品體驗。
- 未來若要使用真實資料與 AI，會先處理同意、隱私、模型驗證與後端安全。

## 4. Demo 前置資料

唯一允許的展示資料：

- 完全虛構的學生名稱與 profile
- 台灣五科的合成紀錄
- 至少 6 週趨勢
- 數學風險與黃金時段能由 fixture 明確重現
- 調整前後的兩組情境資料，並標示為合成／示意

禁止：

- 真實姓名、學號、學校、班級、成績或作答紀錄
- 由真實學生資料改名後直接展示
- 無法追溯來源的第三方圖片、字型或研究圖表

## 5. 展示環境策略

Expo SDK 57 的離線 Demo 已完成；本輪以 Web static export 做實際展示驗收。2026-08-16 已成功產生可側載的 Android release-mode APK（debug certificate 簽署），學生可從 repository 的 [`downloads/`](../downloads/README.md) 下載，並以同目錄 SHA-256 檔校驗；但尚未完成原生裝置上的人工安裝與操作確認。

建議準備：

1. 主要：實體 Android 安裝已預熱的 APK，或 iOS Simulator／Android Emulator 中已預熱的 App。
2. 備案：本機 Web build／dev server。
3. 最後備案：預先錄製的完整操作影片與關鍵畫面截圖。

目前 Expo 官方在 SDK 57 過渡期提醒，商店版 Expo Go 實機可能需要 SDK 54；因此在實際設備驗證前，不把 Expo Go 當成唯一展示方案。

Demo 必須能在無外網狀態使用既有依賴與 fixture 啟動。若現場設備需重新安裝依賴，視為展示風險。

## 6. 恢復與失敗備案

- 提供「重設 Demo」操作，立即回到標準情境。
- fixture 載入失敗時顯示錯誤與重試，不出現白畫面。
- 圖表顯示失敗時保留文字摘要。
- 主要裝置故障時切換 Web fallback。
- 所有網路能力都不在 Demo 關鍵路徑。

## 8. 原企劃數據的使用限制

原始簡報引用「Gallup 2024」與《AI 教育大調查》，但缺少完整報告名稱、網址、樣本數、地區、題目定義與頁碼；部分簡報文字和圖示比例也不一致。

在來源補齊前：

- 不把「60%」「55%」「75%」作為正式競賽證據。
- 不在 README 或 Demo 中重複這些數字。
- 若簡報保留，須標示來源待核實或改成不含百分比的趨勢敘述。

需補的證據：

- 完整原始報告與可公開 URL
- 指標的原始問法與母體
- 樣本數、地區與年份
- 簡報圖表和原始數據的對應方式
